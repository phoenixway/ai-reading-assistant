# AI Reading Assistant

Android-застосунок для читання, узагальнення та аналізу вебсторінок за допомогою локальних LLM у домашній або офісній Wi-Fi мережі.

## Головний сценарій

1. У браузері виберіть **Поділитися** → **agent008**.
2. Застосунок завантажить URL, очистить HTML до тексту та додасть його до чату як контекст.
3. Запитуйте короткий виклад, ключові факти або відповіді лише за вмістом цієї сторінки.

У чаті можна також додати URL вручну, застосувати збережений шаблон і зберегти введений текст як новий prompt.

## Локальний сервер

У «Налаштуваннях» укажіть LAN IP комп'ютера, порт, провайдера та модель:

- **Ollama**: типовий порт `11434`, API `/api/chat`;
- **llama.cpp** (`llama-server`): типовий порт `8080`, OpenAI-сумісний API `/v1/chat/completions`.

Телефон і сервер мають бути в одній Wi-Fi мережі. Для Ollama сервер має слухати не тільки `localhost` (наприклад, через `OLLAMA_HOST=0.0.0.0:11434`).

## Збірка

Відкрийте теку у Android Studio, оберіть встановлений Android SDK та запустіть `assembleDebug`.

У цьому проєкті SDK налаштований локально в `.android-sdk`. Команди `make` та `make debug-cycle` перед збіркою перевіряють, що на диску є щонайменше 5 ГіБ вільного місця.
